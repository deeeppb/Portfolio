ANPR: Automatic Number Plate Recognition

A system that looks at a picture or video of a vehicle, finds the number plate and reads the text on it. In the example, the plate DL 3C BP 2331 is picked out of the car and shown in the software window.

How it works

  1. Capture a frame from an image or video.
  2. Find the number plate on the vehicle.
  3. Clean up the plate image and separate the characters.
  4. Read the characters with OCR.
  5. Show or save the plate number.

Where it is used

  • Toll booths and parking lots
  • Traffic rule enforcement
  • Entry gates of buildings and societies

Technologies

  • Python
  • OpenCV
  • OCR
  • Git

Hand Gesture Recognition

A real-time app that uses the webcam to find a hand, mark 21 key points on it and recognise the gesture. The screen shows which hand it sees (Right: Open), the current gesture (Stop) and the speed at about 30 frames per second.

How it works

  1. Read live video from the webcam.
  2. Detect the hand and its key points on every frame.
  3. Compare the key points with known gestures.
  4. Show the result on screen along with the FPS.

Features

  • Left and right hand detection
  • Real-time speed of about 30 FPS
  • A logging mode to record key points for new gestures

Technologies

  • Python
  • OpenCV
  • MediaPipe
  • Git
